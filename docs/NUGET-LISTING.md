# NuGet listing optimization

Use this checklist before publishing a new version.

## Metadata

- Package icon present and branded (`icon.png`)
- Repository URL set
- Project URL set
- README packed and visible on NuGet
- Description includes problem + value + frameworks
- Tags include high-intent search terms

## Core package discovery tags

Recommended tags used in this repo:

`testing`, `assertions`, `unit-testing`, `integration-testing`, `snapshot-testing`, `xunit`, `nunit`, `mstest`, `dotnet`, `csharp`, `aot`, `mit`

## NuGet page copy guidance

- First sentence: what it does in one line.
- Second sentence: who it is for and where it fits.
- Third sentence: strongest differentiator (license, speed, AOT, migration fit).

## Quality signals on listing/repo

- CI badge passing
- Clearly maintained changelog
- Compatibility matrix
- Active release notes
