# Distribution checklist

Use this checklist for each release to improve adoption and downloads.

## 1) Release assets

- Publish release notes with concrete examples
- Link to quickstart and recipes
- Highlight one "new in this version" snippet

## 2) Community distribution

- Post to relevant .NET Discord/Slack communities
- Share in r/dotnet with practical code examples
- Publish a short dev.to or Medium post
- Share on LinkedIn/X with before/after test code

## 3) Developer trust

- Keep badges green
- Keep changelog current
- Keep compatibility matrix current

## 4) Conversion support

- Keep `README.md` first screen installable in under 5 minutes
- Keep recipes copy/paste ready
- Keep migration comparison current

## 5) Follow-up loop

- Measure download changes 7 and 30 days post-release
- Log what channel drove the biggest uplift
- Reuse best-performing release message format
